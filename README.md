# ShiftOnDuty

- `/` — página para instalar (detecta iPhone o Android).
- `/app/` — app web para iPhone (se instala con Safari → Agregar a pantalla de inicio; funciona sin internet).
- Android: los botones descargan la APK oficial vigente desde GitHub Releases (`charliedays2020/shiftonduty-apk`).
- `/cal/` — página puente que pasa los turnos al Calendario del iPhone. Los datos viajan en el link después del `#` y nunca se envían a ningún servidor.

Este repositorio no contiene datos personales: los nombres del personal van como huellas (hash). El código fuente está en un repositorio privado.
